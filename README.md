# Student Vectors

Docs site: **https://arshiashahbazi83.github.io/student-vectors/**

Turning course enrollments into two vectors per student — friends (MCA on group choices) and field of study
(course→field priors, log-lift update, √-map to the unit sphere) — stored in a vector database and used for recommendations.

- `index.html` — the documentation site (GitHub Pages, served from `main` / root)
- `student_vectors.ipynb` — full pipeline as a notebook
- `student_vectors.py`, `make_fake_data.py` — same pipeline as scripts + synthetic data generator

All data shown on the site is synthetic.
